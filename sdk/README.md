# Language SDKs (`sdk/`)

This directory houses language-specific SDK implementations for Palmshed Sandbox:

- `typescript/`: Reference TypeScript / Node.js SDK (published to npm as `@palmshed/sandbox`).
- `rust/`: Rust SDK (F1 `palmshed-sandbox` crate; native OS glue, same spec contract, independent 0.x line).
- `go/`: Go SDK (planned, future unit F2).
- `python/`: Python SDK for AI agent frameworks (planned, future unit F3).
