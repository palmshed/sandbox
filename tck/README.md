# Technology Compatibility Kit (`tck/`)

The TCK provides test suites for certifying external SDK and backend implementations against the Palmshed Sandbox Runtime Specification.

- `lifecycle/`: Module verification for sandbox creation and destruction contracts.
- `execution/`: Process launch, streaming, cancellation, and exit code contracts.
- `filesystem/`: Virtual filesystem transfers and isolations.
- `networking/`: Network isolation policy enforcement.
- `resources/`: CPU, memory, and timeout caps.
