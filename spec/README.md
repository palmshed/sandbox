# Runtime Specification (`spec/`)

This directory contains the canonical runtime specification for Palmshed Sandbox (`palmshed/sandbox`).

- `sandbox.schema.json`: JSON Schema for Sandbox options.
- `exec.schema.json`: JSON Schema for execution input/output payloads.
- `filesystem.schema.json`: JSON Schema for virtual filesystem transfers.
- `capabilities.schema.json`: Capability negotiation schema.
- `version.md`: Versioning contract.
- `CHANGELOG.md`: Specification revision changelog.
- `compatibility.md`: SemVer compatibility guarantees.
- `deprecations.md`: Scheduled deprecations.
